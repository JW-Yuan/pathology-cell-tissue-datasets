# PAIP2023 数据集详情

## 数据集描述

PAIP2023（Pathology AI Platform Challenge 2023）是 PAIP 系列挑战赛的 2023 年版本，进一步扩展了多器官覆盖范围，重点关注**多器官组织分割**任务，涵盖胰腺和结肠等多种组织类型。

## 数据集基本信息

- **器官类型**：多器官（胰腺 + 结肠等）
- **染色方式**：H&E（苏木精-伊红）
- **数据集大小**：Patch 数量待官方公布（见官方数据集页面）
- **图像类型**：1024 × 1024 像素 Patch
- **放大倍数**：
  - 胰腺数据：20x 或 40x 扫描
  - 结肠数据：40x 扫描
- **任务类型**：分割（Semantic Segmentation）

```python
import numpy as np
```

## 数据特点

### 1024×1024 Patch 格式
- 使用标准化的 1024×1024 patch 格式，适合直接输入现代深度学习模型
- 较大的 patch 尺寸包含更多上下文信息

### 多放大倍数
- 胰腺数据包含 20x 和 40x 两种放大倍数
- 需注意不同放大倍数下视野范围差异

### PAIP 延续
- 延续 PAIP2019-2021 的数据积累，与前期数据集互补

## 使用建议

### 数据加载

```python
import os
import numpy as np
from PIL import Image
import glob

def load_paip2023_patches(root_dir, split='train'):
    """加载 PAIP2023 patch 数据集"""
    img_dir = os.path.join(root_dir, split, 'images')
    mask_dir = os.path.join(root_dir, split, 'masks')
    
    img_paths = sorted(glob.glob(os.path.join(img_dir, '*.png')))
    
    dataset = []
    for img_path in img_paths:
        fname = os.path.basename(img_path)
        mask_path = os.path.join(mask_dir, fname)
        
        img = np.array(Image.open(img_path).convert('RGB'))  # (1024, 1024, 3)
        if os.path.exists(mask_path):
            mask = np.array(Image.open(mask_path).convert('L'))  # (1024, 1024)
        else:
            mask = None
        
        dataset.append({'image': img, 'mask': mask, 'filename': fname})
    
    return dataset
```

### 多放大倍数处理

```python
# 不同放大倍数的图像需要处理视野范围差异
# 20x 下 1024px 对应的物理尺寸约为 20x 下 512px 的 2 倍

def normalize_magnification(img, source_mag, target_mag=40):
    """将不同放大倍数的图像统一到目标放大倍数"""
    scale = source_mag / target_mag
    if scale != 1.0:
        new_size = (int(img.shape[1] * scale), int(img.shape[0] * scale))
        img_pil = Image.fromarray(img)
        img_resized = img_pil.resize(new_size, Image.BILINEAR)
        return np.array(img_resized)
    return img
```

### 评估指标

```python
# Dice 系数和 mIoU（多类分割）
import numpy as np

def mean_iou(pred, gt, num_classes):
    ious = []
    for c in range(num_classes):
        pred_c = (pred == c)
        gt_c = (gt == c)
        intersection = (pred_c & gt_c).sum()
        union = (pred_c | gt_c).sum()
        if union > 0:
            ious.append(intersection / union)
    return np.mean(ious) if ious else 0.0
```

## 注意事项

1. **数据访问**：通过 Grand Challenge 官方页面或 wisepaip.org 申请下载。
2. **放大倍数差异**：胰腺数据包含 20x 和 40x 两种，训练前需统一处理。
3. **PAIP 系列完整性**：建议参照 PAIP2019-2023 的完整系列，以了解任务演变和数据扩充历史。
4. **大尺寸 Patch**：1024×1024 px 的 patch 输入需要较大显存，训练时注意 batch size 设置。
