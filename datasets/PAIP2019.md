# PAIP2019 数据集详情

## 数据集描述

PAIP2019（Pathology AI Platform Challenge 2019）是由韩国首尔国立大学医院（SNUH）主办的病理 AI 挑战赛数据集，专注于**肝细胞癌（Hepatocellular Carcinoma, HCC）全切片图像中的肿瘤分割**任务。

### 挑战赛任务

- **Task 1**：肿瘤区域分割（Viable tumor area segmentation）
- **Task 2**：肿瘤负荷估计（Whole tumor area ratio，相对于整个肝组织的比例）

## 数据集基本信息

- **器官类型**：肝脏（Liver）— 肝细胞癌（HCC）
- **染色方式**：H&E（苏木精-伊红）
- **数据集大小**：
  - 训练集：50 张 WSI
  - 验证集：10 张 WSI
  - 测试集：40 张 WSI
- **放大倍数**：20x
- **扫描仪**：Aperio AT2
- **任务类型**：分割（Semantic Segmentation）

## 数据集划分

| 子集 | 数量 | 说明 |
|------|------|------|
| 训练集 | 50 | 含肿瘤区域像素级标注 |
| 验证集 | 10 | 含标注 |
| 测试集 | 40 | 评估用（标注不公开）|
| **合计** | **100** | — |

## 标注格式

### 二值掩码（Binary Mask）

- 标注包含两层掩码：
  1. **活性肿瘤区域（Viable tumor area）**：像素级二值掩码
  2. **整体肿瘤区域（Whole tumor area）**：包含活性和坏死区域的肿瘤总范围

```python
import openslide
import numpy as np
from PIL import Image

# 加载 WSI
wsi = openslide.OpenSlide('liver_cancer_001.svs')

# 加载活性肿瘤掩码
viable_mask = np.array(Image.open('liver_cancer_001_viable.png').convert('L'))
whole_mask = np.array(Image.open('liver_cancer_001_whole.png').convert('L'))

# 二值化
viable_binary = (viable_mask > 0).astype(np.uint8)
whole_binary = (whole_mask > 0).astype(np.uint8)

# 计算肿瘤负荷（Task 2）
liver_tissue_area = whole_binary.sum()  # 近似肝组织面积（实际需组织检测）
viable_tumor_area = viable_binary.sum()
tumor_burden = viable_tumor_area / (liver_tissue_area + 1e-8)
```

## 数据特点

### 双层标注
- 区分**活性肿瘤（Viable）**和**坏死肿瘤（Necrotic）**区域
- 活性肿瘤的精确检测对治疗反应评估至关重要

### 肝细胞癌特异性
- HCC 是全球最常见的原发性肝癌，预后差
- 自动化肿瘤分割可辅助外科手术规划和疗效监测

### Aperio AT2 标准化
- 全部使用 Aperio AT2 扫描仪，图像质量标准化程度高

## 使用建议

### 大 WSI 的 Patch 提取

```python
import openslide
import numpy as np
from PIL import Image

def extract_foreground_patches(wsi_path, mask_path, patch_size=512, level=1):
    """提取含有标注区域的 patch"""
    wsi = openslide.OpenSlide(wsi_path)
    mask = Image.open(mask_path).convert('L')
    
    # 下采样到 level 1
    w_l1, h_l1 = wsi.level_dimensions[level]
    scale = wsi.level_downsamples[level]
    
    mask_resized = mask.resize((w_l1, h_l1), Image.NEAREST)
    mask_array = np.array(mask_resized)
    
    patches = []
    step = patch_size
    
    for y in range(0, h_l1 - patch_size, step):
        for x in range(0, w_l1 - patch_size, step):
            patch_mask = mask_array[y:y+patch_size, x:x+patch_size]
            
            if patch_mask.sum() > 0:  # 含肿瘤区域
                # 读取对应 WSI 区域
                x_l0 = int(x * scale)
                y_l0 = int(y * scale)
                patch = wsi.read_region((x_l0, y_l0), level, (patch_size, patch_size))
                patches.append({
                    'image': np.array(patch.convert('RGB')),
                    'mask': patch_mask
                })
    
    return patches
```

### 评估指标

```python
# Task 1: 像素级分割 - Jaccard 指数
def jaccard_index(pred, gt):
    intersection = ((pred == 1) & (gt == 1)).sum()
    union = ((pred == 1) | (gt == 1)).sum()
    return intersection / (union + 1e-8)

# Task 2: 肿瘤负荷 - 连续值 RMSE
import numpy as np
def tumor_burden_rmse(pred_burdens, gt_burdens):
    return np.sqrt(((np.array(pred_burdens) - np.array(gt_burdens))**2).mean())
```

## 注意事项

1. **双层标注**：活性肿瘤和整体肿瘤区域是两个不同的标注层，Task 1 和 Task 2 分别使用不同层。
2. **WSI 大小**：肝脏 WSI 通常较大，单张可达 50,000×50,000 px，处理时需注意内存管理。
3. **数据访问**：需通过 Grand Challenge 平台注册申请数据。
4. **PAIP 系列**：PAIP 还发布了 2020（结肠癌）、2021（多器官）和 2023（多器官）版本，可联合使用。
