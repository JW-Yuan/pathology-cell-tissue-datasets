# PAIP2021 数据集详情

## 数据集描述

PAIP2021（Pathology AI Platform Challenge 2021）是 PAIP 系列的第三届挑战赛，首次引入**多器官**场景，同时覆盖结肠癌、前列腺癌和胰腺癌三种肿瘤类型，任务为泛癌多器官肿瘤分割。

### 多器官意义

PAIP2021 的多器官设计旨在开发可跨器官类型泛化的通用肿瘤分割算法，这是计算病理领域向泛化性 AI 的重要探索。

## 数据集基本信息

- **器官类型**：多器官（结肠、前列腺、胰腺）
- **染色方式**：H&E（苏木精-伊红）
- **数据集大小**：
  - 训练集：150 张 WSI（每种器官 50 张）
  - 验证集：30 张 WSI（每种器官 10 张）
  - 测试集：60 张 WSI（每种器官 20 张）
- **放大倍数**：20x — Aperio AT2
- **任务类型**：分割（Multi-organ Tumor Segmentation）

## 数据集划分

| 子集 | 结肠 | 前列腺 | 胰腺 | 合计 |
|------|------|--------|------|------|
| 训练集 | 50 | 50 | 50 | 150 |
| 验证集 | 10 | 10 | 10 | 30 |
| 测试集 | 20 | 20 | 20 | 60 |
| **合计** | **80** | **80** | **80** | **240** |

## 器官肿瘤特征

| 器官 | 肿瘤类型 | 主要组织学特征 |
|------|---------|--------------|
| 结肠 | 结直肠腺癌 | 腺体结构、黏液成分 |
| 前列腺 | 前列腺腺癌 | 腺体增生、浸润基质 |
| 胰腺 | 胰腺导管腺癌（PDAC）| 促纤维增生性间质、腺体结构 |

## 标注格式

### XML 格式（QuPath 兼容）

```python
import xml.etree.ElementTree as ET
import numpy as np
from PIL import Image, ImageDraw

def parse_paip2021_annotation(xml_path, wsi_size):
    """解析 PAIP2021 XML 格式标注"""
    tree = ET.parse(xml_path)
    root = tree.getroot()
    
    mask = Image.new('L', wsi_size, 0)
    draw = ImageDraw.Draw(mask)
    
    for region in root.iter('Region'):
        vertices = []
        for vertex in region.iter('Vertex'):
            x = float(vertex.get('X'))
            y = float(vertex.get('Y'))
            vertices.append((x, y))
        
        if len(vertices) > 2:
            draw.polygon(vertices, fill=1)
    
    return np.array(mask)
```

## 数据特点

### 首次多器官 PAIP 数据集
- 同时覆盖三种器官，推动跨器官泛化研究
- 可用于训练多任务学习或通用分割模型

### 胰腺癌挑战
- 胰腺导管腺癌（PDAC）的促纤维增生性间质（Desmoplastic stroma）使肿瘤边界模糊
- 被认为是三种器官中分割难度最大的

### 统一标注规范
- 三种器官使用统一的标注规范和评估方式，便于跨器官对比

## 使用建议

### 多器官批处理

```python
import os
import openslide
import numpy as np

ORGANS = ['colon', 'prostate', 'pancreas']

def load_paip2021_dataset(root_dir, split='train'):
    dataset = {}
    for organ in ORGANS:
        wsi_dir = os.path.join(root_dir, organ, split, 'images')
        ann_dir = os.path.join(root_dir, organ, split, 'annotations')
        
        dataset[organ] = []
        for fname in os.listdir(wsi_dir):
            if fname.endswith('.svs') or fname.endswith('.ndpi'):
                wsi_path = os.path.join(wsi_dir, fname)
                ann_path = os.path.join(ann_dir, fname.replace('.svs', '.xml'))
                dataset[organ].append({'wsi': wsi_path, 'annotation': ann_path})
    
    return dataset
```

### 评估指标

```python
# 每类器官分别计算 Jaccard 指数，再取均值
def evaluate_multi_organ(pred_masks, gt_masks, organs):
    per_organ_jaccard = {}
    
    for organ in organs:
        pred_organ = pred_masks[organ]
        gt_organ = gt_masks[organ]
        
        intersection = ((pred_organ == 1) & (gt_organ == 1)).sum()
        union = ((pred_organ == 1) | (gt_organ == 1)).sum()
        
        per_organ_jaccard[organ] = intersection / (union + 1e-8)
    
    mean_jaccard = sum(per_organ_jaccard.values()) / len(organs)
    return per_organ_jaccard, mean_jaccard
```

## 注意事项

1. **多器官评估**：需分别报告每种器官的分割结果，不可合并计算。
2. **胰腺难度**：胰腺癌间质丰富，肿瘤与间质边界模糊，建议单独调优。
3. **放大倍数统一**：三种器官统一使用 20x，有利于通用模型训练。
4. **PAIP 完整系列**：建议与 PAIP2019、2020、2023 联合研究，构建多年度、多器官的综合基准。
