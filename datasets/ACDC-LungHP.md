# ACDC-LungHP 数据集详情

> 参考 PanNuke 详情页的章节结构，严格区分官方已发布信息、当前收录的版本与尚不能核实的部分。资料核查：2026-10-08。

## 数据集描述

肺组织病理全切片自动评估挑战数据。主要为肺癌相关区域的识别/分割；赛事可能有不同阶段，不能把某一阶段的组织分类要求默认成逐像素核标注。

## 任务与标注

官方 WSI TIFF 与 XML；原始 XML 不是 LabelImg bbox、随意四类语义 PNG 或官方附带 mask 目录。

## 数据划分与评估协议

Stage One 公开 150 张含参考标注的训练样本，剩余 50 张测试样本。

## 文件结构与读取方法

- WSI TIFF：大尺寸扫描病理切片
- XML：人工勾画区域标注；可配合 ASAP 查看

这些是有来源依据的**文件组成**，不是未经下载验证的精确文件树。不同 release 和镜像可能调整压缩包名或子目录；先检查实际压缩包/路径：

```python
from pathlib import Path
root = Path('DATASET_ROOT')  # 替换为已下载并解压的数据目录
for p in sorted(root.rglob('*')):
    if p.is_file():
        print(p.relative_to(root), p.suffix)
```

## 使用建议（简要）

### 加载与预处理

- 官方提醒同一玻片可能有多个组织碎片，其中只有一个组织被勾画，其余区域训练时需排除。
- 核实样本与标注的一一对应关系，并保留原始标签文件的版本号与来源信息。
- 如果提供了病例/玻片 ID，优先使用**患者或玻片级**数据划分，避免相邻 patch 泄漏。

### 建模提示

- 原站点旧说明不可据此杜撰每张标注数量、类别比例或不存在的 GitHub 源码链接。

### 评估指标

依据分割阶段采用 Dice/IoU；如涉及分类须以阶段评测指标为准。
