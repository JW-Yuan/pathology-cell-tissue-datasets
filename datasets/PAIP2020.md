# PAIP2020 数据集详情

## 数据集描述

PAIP2020（Pathology AI Platform Challenge 2020）是 PAIP 系列挑战赛的 2020 年版本，聚焦于**结肠癌（Colorectal Cancer）全切片图像的肿瘤分割**任务。相较于 PAIP2019（肝脏），本数据集提高了放大倍数（40x），并覆盖了结肠癌场景。

## 数据集基本信息

- **器官类型**：结肠（Colon）— 结肠癌（Colorectal Cancer）
- **染色方式**：H&E（苏木精-伊红）
- **数据集大小**：
  - 训练集：47 张 WSI
  - 验证集：31 张 WSI
  - 测试集：40 张 WSI
- **放大倍数**：40x
- **扫描仪**：Aperio AT2
- **任务类型**：分割（Semantic Segmentation）

## 数据集划分

| 子集 | 数量 | 说明 |
|------|------|------|
| 训练集 | 47 | 含肿瘤区域像素级标注 |
| 验证集 | 31 | 含标注 |
| 测试集 | 40 | 评估用 |
| **合计** | **118** | — |

## 标注格式

### 二值掩码（Binary Mask）

```python
import openslide
import numpy as np
from PIL import Image

# 加载结肠癌 WSI
wsi = openslide.OpenSlide('colon_cancer_001.svs')

# 加载肿瘤区域二值掩码
tumor_mask = np.array(Image.open('colon_cancer_001_mask.png').convert('L'))
binary_mask = (tumor_mask > 0).astype(np.uint8)

# 计算肿瘤面积占比
tumor_ratio = binary_mask.mean()
print(f"肿瘤区域占 WSI 面积的 {tumor_ratio*100:.2f}%")
```

## 结肠癌组织学特征

| 特征 | 说明 |
|------|------|
| 腺癌结构 | 腺体结构异常，腔不规则 |
| 肿瘤浸润 | 肿瘤侵入周围间质 |
| 核异型性 | 细胞核大、多形、深染 |
| 间质反应 | 纤维间质（促纤维增生性间质）增生 |

## 数据特点

### 40x 高分辨率
- 40x 扫描倍数（相比 PAIP2019 的 20x）分辨率更高
- 提供更精细的肿瘤形态学信息

### 结肠癌 vs 肝癌
- 与 PAIP2019 结合，可研究不同器官、不同病理特征对分割模型的影响
- 结肠癌腺体结构复杂，分割难度较高

## 使用建议

### Patch 提取与训练

```python
import openslide
import numpy as np
from PIL import Image

def create_patch_dataset(wsi_path, mask_path, patch_size=1024, 
                          level=0, overlap=0.5):
    """创建结肠癌分割训练 patch 集"""
    wsi = openslide.OpenSlide(wsi_path)
    w, h = wsi.level_dimensions[level]
    
    # 加载并调整掩码大小
    mask = Image.open(mask_path).convert('L')
    mask_resized = mask.resize((w, h), Image.NEAREST)
    mask_array = np.array(mask_resized)
    
    stride = int(patch_size * (1 - overlap))
    patches = []
    
    for y in range(0, h - patch_size + 1, stride):
        for x in range(0, w - patch_size + 1, stride):
            patch_mask = mask_array[y:y+patch_size, x:x+patch_size]
            tumor_ratio = (patch_mask > 0).mean()
            
            # 只保留含有一定比例肿瘤的 patch
            if tumor_ratio > 0.05:
                patch_img = wsi.read_region((x, y), level, (patch_size, patch_size))
                patches.append({
                    'image': np.array(patch_img.convert('RGB')),
                    'mask': (patch_mask > 0).astype(np.uint8)
                })
    
    return patches
```

### 评估指标

```python
# Jaccard 指数（官方主要指标）
def jaccard_coefficient(pred, gt):
    intersection = ((pred == 1) & (gt == 1)).sum()
    union = ((pred == 1) | (gt == 1)).sum()
    return intersection / (union + 1e-8)

# Dice 系数
def dice_coefficient(pred, gt):
    intersection = ((pred == 1) & (gt == 1)).sum()
    return 2 * intersection / (pred.sum() + gt.sum() + 1e-8)
```

## 注意事项

1. **WSI 大小**：40x 的结肠 WSI 分辨率极高，单张可超过 80,000×80,000 px，处理时注意内存。
2. **数据访问**：需在 Grand Challenge 平台注册后申请数据。
3. **PAIP 系列关联**：建议与 PAIP2019（肝脏）和 PAIP2021（多器官）联合研究。
4. **MSI 预测可能性**：PAIP2020 的数据同样适用于微卫星不稳定性（MSI）预测研究，可参考 GitHub 代码。
